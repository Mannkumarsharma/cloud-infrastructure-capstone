# 📚 Infrastructure Lab Documentation Guide

## 📌 Overview

This directory provides guidance for navigating and using the learning materials in the Cloud Infrastructure & Systems Administration repository.

The repository contains lab PDFs and topic-specific documentation covering Linux, Windows Server, networking, virtualization, monitoring, storage, scripting, middleware, and database fundamentals.

## 🗂️ How to Use This Repository

1. Start with the main [README](../README.md) to understand the project and explore the learning roadmap.
2. Select a technical domain from the repository navigation table.
3. Read the domain-specific `README.md` before opening its lab PDF.
4. Follow the exercises and review the relevant concepts.
5. Practise in an appropriate lab environment and verify your results.
6. Record your observations, errors, troubleshooting steps, and lessons learned.

## 🧪 Recommended Lab Workflow

For each lab, follow this general workflow:

1. **Understand the objective:** Identify what the exercise is intended to demonstrate.
2. **Review the requirements:** Check prerequisites, tools, and environment requirements.
3. **Perform the steps:** Follow the documented procedure carefully.
4. **Verify the result:** Use appropriate commands, settings, logs, or interface checks.
5. **Troubleshoot:** Investigate unexpected results and document the resolution.
6. **Record the outcome:** Note what worked, what you learned, and any remaining questions.

## 🛡️ Safe Practice Guidelines

- Use a personal or authorized lab environment.
- Avoid making changes to production systems without appropriate authorization.
- Take VM snapshots or backups when appropriate before risky configuration changes.
- Never publish passwords, access tokens, private keys, confidential information, or sensitive organizational data.
- Verify commands and configuration changes before executing them.

## 🎯 Learning Objectives

By using these materials and documenting practical exercises, learners can develop familiarity with infrastructure administration concepts, configuration verification, troubleshooting workflows, and technical documentation.

## ⚠️ Disclaimer

This repository is intended for educational and reference purposes. The included materials describe lab exercises and technical concepts; the presence of a topic does not imply mastery or professional certification.
