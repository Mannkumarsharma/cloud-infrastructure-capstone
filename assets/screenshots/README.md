# 📸 Screenshots and Technical Evidence

## Purpose

This directory is intended for screenshots and other visual evidence that help explain infrastructure lab exercises and their verified outcomes.

## What to Include

Examples of useful evidence include:

- Linux command output demonstrating file permissions or ownership.
- Windows Server administration and monitoring interfaces.
- Active Directory or DNS configuration in a practice environment.
- Network configuration and connectivity test results.
- VMware or Hyper-V lab configurations.
- Infrastructure monitoring dashboards.
- Storage configuration or database exercises.

Only include evidence that is relevant to the repository and that you are authorized to share.

## Screenshot Guidelines

1. Capture screenshots from your own practice environment whenever possible.
2. Use clear, descriptive filenames.
3. Add a short explanation of what each screenshot demonstrates.
4. Remove or obscure passwords, usernames where sensitive, IP addresses where sensitive, tokens, hostnames, and other confidential information as appropriate.
5. Never upload confidential company screenshots, production-system information, or materials you do not have permission to publish.

## Suggested Naming Convention

Use descriptive filenames such as:

- `linux-file-permissions.png`
- `windows-server-monitoring.png`
- `dns-configuration.png`
- `network-connectivity-test.png`
- `virtual-machine-settings.png`

These are examples of naming conventions, not screenshots that already exist in this repository.

## Evidence Quality

Screenshots should support a specific explanation or demonstrate a result. Avoid adding images that do not contribute meaningful technical information.

## Note

Only describe a configuration or result as verified when you have actually checked it in the relevant lab environment.
